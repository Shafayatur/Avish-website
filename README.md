# Avish - Luxury Beauty

Premium e-commerce platform for Avish Lifestyle — a luxury cosmetics brand.

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- Supabase (database, auth, storage)
- Framer Motion
- Three.js (3D logo)
- Deployed on Vercel

## Features
- Full e-commerce (shop, cart, checkout, wishlist)
- User authentication
- Admin dashboard (products, orders, customers, banners, reviews)
- Dark/light theme
- Responsive design
- 3D logo with PBR materials

## Development
```bash
npm install
npm run dev
```

## Environment Variables
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_anon_key
```
